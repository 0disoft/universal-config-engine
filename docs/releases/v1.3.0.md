# Universal Config Engine 1.3.0

Release date: 2026-10-26.

Minor release for local application adoption and bounded configuration reload.
All five packages use `1.3.0` and npm `latest`. This promotes verified candidate
`1.3.0-rc.1` at `6ebaa707aff611a8552886bee63fad11d7fee68b` without runtime,
public declaration, dependency, package README, fixture or runner changes.

## Added

- Official JSONC/YAML/TOML/JSON5 loaders with bounded parsing, sanitized syntax
  positions and on-demand parser loading, alongside JSON and dotenv.
- Node `loadConfig` / `loadValidatedConfig`, Standard Schema and separate typed
  output, sharing declaration execution and validation with the CLI.
- Bounded discovery, profiles/inheritance, dependency notifications and
  `watchConfig` for automatic declaration/source graph subscriptions.
- Serialized disposable reload/watch, last-good snapshots, cancellation,
  deadlines, missing-file repair and bounded directory/handle tracking.
- CLI help/version, init/doctor and public-share reports; explicit numeric/empty
  mapping policies, comparison dimensions and opt-in public validator constraints.

## Security and reliability

- Require patched Zod >=4.6.6 within major 4; this candidate was validated with
  4.6.7. Applications using an older Zod must update it before this adapter.
  Addresses [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
- Refresh locked fast-uri to patched 3.1.9 within its existing major range.
- Preserve secret policy across overrides, atomic arrays and report overflow.
  Snapshot admitted arrays and avoid reading already failed source payloads.
- Bound structural admission, aggregate merge/coercion work, diagnostic retention,
  redaction fallback memory and watcher setup; retain private causes out of band.
- Reuse CI builds while keeping Linux/Windows and minimum/current Node coverage;
  canonicalize Windows test fixtures to handle short temporary-directory aliases.

## Compatibility and verification

Node.js >=24 and ESM remain required. Existing default report schema `0.2` and
inspection/diff/change-policy envelopes remain compatible. Existing default
mapping/comparison behavior is retained. Keep all five packages aligned:

```sh
npm install @0disoft/universal-config-engine-core@1.3.0 @0disoft/universal-config-engine-node@1.3.0
npm install --save-dev @0disoft/universal-config-engine-cli@1.3.0
```

See [the adoption example](../../examples/adoption/README.md),
[official files](../adapters/official-files.md), [reload/watch](../adapters/reload.md),
[typed validation](../library/typed-validation.md) and

Stable publication requires successful exact-commit CI, CodeQL, packed consumers,
runtime compatibility, release dry-run, 5/5 candidate publication and public
registry installation. Candidate tarballs match npm integrity and SLSA provenance
metadata. Final assets retain publication manifests, independent verification and
a commit-bound SPDX SBOM. Alternate-runtime evidence remains limited to the
documented historical local checks; this release does not widen the engine claim.
If a regression is found, pin stable `1.2.0`; published versions/tags are immutable.
