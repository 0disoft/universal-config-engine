# Universal Config Engine 1.1.2

Release date: 2026-10-21.

This patch promotes `1.1.2-rc.1` from
`cbcb1abd6e941d7ef8fb08401dd868861caaac63` without runtime, public declaration,
dependency or package README changes. All five packages use `1.1.2` and npm `latest`.

## Fixed

- Validation shares one provenance budget between incoming history and new events.
  Pipelines no longer subtract incoming history twice, and direct `runValidators`
  calls stop further adapters before that combined budget is exceeded. Two existing
  events with a total cap of three now allow one validator and preserve its event.
- The Ajv adapter rejects unsupported `$async: true` schemas at creation before
  starting a validation Promise. This enforces the existing synchronous Schema
  input contract for JavaScript callers and prevents false successful results.
- Development tooling explicitly owns its Vite peer and uses 8.1.6 throughout the
  test graph, resolving three advisories in the previous 8.1.3 development dependency.
  Published package runtime dependencies are unchanged.

## Compatibility

No public exports, types, CLI commands, exit codes or report schema changed.
Node.js >=24 and ESM remain required. Direct validator callers should budget both
incoming history and new events. Unsupported async Ajv schemas now fail at setup;
this release does not add async Ajv schema support. Install packages at the same version:

```sh
npm install @0disoft/universal-config-engine-core@1.1.2 @0disoft/universal-config-engine-node@1.1.2
npm install --save-dev @0disoft/universal-config-engine-cli@1.1.2
```

Optional adapters are `@0disoft/universal-config-engine-validator-ajv` and
`@0disoft/universal-config-engine-validator-zod`. If a regression is found,
consumers can pin stable `1.1.1` while a follow-up patch is prepared; published
versions and tags are immutable.

Publication requires exact-commit CI, CodeQL, minimum/current Node.js checks,
Linux/Windows packed consumers, release dry-run, complete candidate evidence and
registry installation checks. Assets retain publication manifests and a
commit-bound SPDX SBOM alongside npm integrity and provenance evidence.
