# Universal Config Engine 1.3.0-rc.1

Release candidate for local application adoption and bounded configuration reload.
All five packages use `1.3.0-rc.1` and npm `next`; npm `latest` remains on
stable `1.2.0` until candidate verification and stable promotion.

## Added

- Official JSONC, YAML, TOML and JSON5 file adapters with bounded parsing and
  sanitized syntax positions, alongside the existing JSON and dotenv adapters.
- Node `loadConfig` and `loadValidatedConfig` facades sharing declaration execution
  with the CLI; Standard Schema support and typed validator outputs.
- Bounded discovery, profiles and inheritance; `onDependencies` notifications
  before declaration/source reads and automatic dependency watching via `watchConfig`.
- Disposable serialized reload/watch controllers with last-good snapshots,
  cancellation, deadlines, repair subscriptions and bounded watch resources.
- CLI help/version, init/doctor, public-share reports, optional strict numeric and
  empty-input mapping policies, independent value/source/location comparisons and
  allowlisted opt-in validator constraints.

## Reliability and security

- Require patched Zod >=4.6.6 (major 4); update an application's existing Zod
  installation before upgrading this adapter. Addresses GHSA-mrhx-c7xc-m3w5.
- Refresh the locked fast-uri dependency to patched 3.1.9 within its existing
  major-version range, addressing the URI normalization advisories.
- Preserve secret policy through overrides, inspection/diff overflow and atomic
  arrays. Keep parser/provider prose and original values out of public diagnostics.
- Enforce structural and aggregate budgets before expensive reads, cloning and
  writes; snapshot array values during validation and skip failed source payloads.
- Bound watcher metadata, file I/O admission, asynchronous provider boundaries,
  diagnostic retention and redaction fallback memory; isolate private error causes.
- Reuse CI builds while retaining the existing OS/Node compatibility coverage.

## Compatibility and verification

Node.js >=24 and ESM remain required. Existing default report schema `0.2` and
inspection/diff/change-policy envelopes remain compatible. Existing callers retain
default mapping/comparison behavior; new options and facade APIs are additive.
Install all five packages at the same exact candidate version.

See [the adoption example](../../examples/adoption/README.md),
[official files](../adapters/official-files.md), [reload/watch](../adapters/reload.md),
[typed validation](../library/typed-validation.md) and
[ADR 0018](../adr/0018-local-config-adoption.md). The complete fix history is in
[CHANGELOG.md](../../CHANGELOG.md).

Stable promotion requires successful exact-commit CI, CodeQL, Linux/Windows and
minimum/current Node consumers, release dry-run, complete 5/5 publication evidence,
npm integrity/provenance and installation from the public registry. Until those
checks finish, this candidate is not a completed stable release. Consumers can pin
`1.2.0` if a regression is found; published versions and tags remain immutable.
