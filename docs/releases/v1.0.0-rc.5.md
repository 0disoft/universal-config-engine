# Universal Config Engine 1.0.0-rc.5

RC5 replaces the RC4 promotion plan because runtime, dependency, packaging
verification, and release-runner changes require fresh candidate validation.

- Ajv keywords outside the core code grammar now return `ajv_custom_keyword`
  without retaining raw keyword text. Standard keyword codes are unchanged.
- Whole-source redaction applies only to contributing sources. Overridden path
  policies and both source/report name patterns remain effective in reports.
- JSON coercion updates resolved leaf paths, rejects unsafe keys explicitly, and
  supports existing array elements while preserving the public object-only setter.
- Flattening emits arrays only after full validation; diagnostic-budget exhaustion
  cannot forward invalid or partially checked arrays to merge.
- Argv mappings consume split values once. Strict mode diagnoses each unconsumed
  token without guessing an unknown option's arity. Lone dotenv quotes stay literal.
- Ajv required/additional-property errors include the affected property, including
  empty names and escaped/numeric-looking keys. Validator numeric path indexes must
  be non-negative safe integers; sparse paths are rejected.
- CLI value parsing rejects following short options. Paths beginning with a dash
  remain available through explicit `--config=...` assignment.
- Internal CLI, diagnostic, test, and package-smoke responsibilities are separated;
  workspace checks build the dependency graph once before running package checks.
- The dependency graph uses patched `fast-uri` and `source-map-js` floors and
  aligned Vitest/V8 coverage 5.0.5 development dependencies.
- Packed CLI consumers exercise usage, missing-declaration, and bounded-input
  failures, checking exit codes and both output channels on Windows and Linux.
- Stable readiness binds candidate tags and workflow results to exact commit
  identities. A separate maintainer governance preflight fails closed on unknown
  permissions, unsafe rulesets, and outstanding security alerts.
- setup-node uses the reviewed immutable v7.0.0 commit. Node.js >=24, public
  declarations, report schema 0.2, CLI commands and exit codes remain unchanged.
- Dependabot owns updates; Renovate is explicitly disabled for this repository.

After publication, install all Universal Config Engine packages at `1.0.0-rc.5`
or use npm `next`. The previous stable version remains npm `latest` until a
separately validated stable release. No stable version is authorized by policy
until RC5's exact published commit and evidence are recorded.
