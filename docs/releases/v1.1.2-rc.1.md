# Universal Config Engine 1.1.2-rc.1

Patch candidate for validation-budget accounting and the Ajv schema boundary.
All five packages use `1.1.2-rc.1` and publish under npm `next`; npm `latest`
remains on `1.1.1` while the candidate is reviewed.

## Fixed

- Validation owns aggregate provenance accounting. The pipeline passes the original
  limit without subtracting incoming history twice. Two existing events with a
  total budget of three now allow one validator to run and retain its event.
- Direct `runValidators` calls count incoming history plus new validation events
  against `maxProvenanceEvents`. Further adapters are skipped before that combined
  budget is exceeded, and failures report the original configured maximum.
- The Ajv adapter rejects `$async: true` schemas at creation, matching its existing
  synchronous `Schema` input type even for JavaScript callers. No validation Promise
  is started or misreported as success. Synchronous results and normalized error
  paths retain their existing behavior.

## Compatibility

No public exports, types, dependencies, CLI commands or report schema changed.
Node.js >=24 and ESM remain required. Direct validator callers should budget both
incoming history and newly generated events. JavaScript consumers passing an
unsupported asynchronous Ajv schema now receive a setup error instead of a false
success; this release does not add async Ajv schema support.

Install this exact candidate or npm `next`. Stable promotion requires successful
exact-commit checks, complete candidate publication evidence, integrity/provenance
verification and registry installation checks.
