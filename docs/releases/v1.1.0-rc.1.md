# Universal Config Engine 1.1.0-rc.1

Release candidate for the next compatible minor release, based on the maintenance
changes since 1.0.0. All five packages share this version and publish under npm
`next`; npm `latest` remains on the previous stable release.

## Additive API

- Node JSON file sources accept optional `maxLocationBytes` (default 4 MiB).
  Excess location metadata is omitted with `max_location_bytes_exceeded` warning;
  parsed configuration values are preserved. This is a metadata budget, not a
  total JavaScript heap limit. Existing callers need no changes.

## Reliability and Maintenance

- Deep JSON parsing, cloning, structural checks, path indexing, location collection
  and validator freezing use iterative traversal, preserving configured limits.
- JSON mappings reject non-finite numbers and unsafe keys before assignment.
- Pipeline loading-limit failures remain errors and skip validators. Diagnostic
  overflow cannot be hidden by an adapter warning with the marker's code.
- Validator, coercion, mapping and argv diagnostic paths remain stable when caller
  arrays are reused; secret-path redaction keeps the original association.
- Literal prototype-like override names are handled as explicit own properties;
  inherited values are ignored. Unicode argv assignment names match split names.
- Loader diagnostic copies respect retention budgets while malformed tail entries
  are still validated. Strict argv diagnostics share the value scan.
- File-source boundaries and resolved-path bookkeeping have separate owners.

Public ESM exports, Node.js >=24, CLI commands/exit codes and diagnostic schema
`0.2` remain compatible. Install an exact `1.1.0-rc.1` version or opt into npm
`next`. Stable promotion requires publication evidence and checks on its own SHA.
