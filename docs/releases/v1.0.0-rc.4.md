# Universal Config Engine 1.0.0-rc.4

`1.0.0-rc.4` is a security-only release candidate that replaces RC3 as the
reviewed source for stable `1.0.0`.

## Security

- Resolves Ajv's transitive `fast-uri` runtime dependency to patched `3.1.5`,
  clearing `GHSA-7p8r-x3mc-p8w7` from the published CLI and Ajv adapter paths.
- Resolves Vite's transitive `postcss` development dependency to patched `8.5.26`,
  clearing `GHSA-r28c-9q8g-f849` without updating the broader Rolldown or
  Lightning CSS graph.
- Replaces RC3 as the candidate that stable promotion must validate.

The package manifests retain their existing Ajv and tool compatibility ranges.
Workspace-level major-range overrides keep the reviewed security floors explicit,
while `pnpm-lock.yaml` records the exact release graph.

## Compatibility

RC4 does not change runtime source, public TypeScript declarations, package
READMEs, fixtures, smoke behavior, CLI contracts, diagnostic schema `0.2`, or the
Node.js `>=24` support range. The five package manifests advance together from
`1.0.0-rc.3` to `1.0.0-rc.4`.

## Install

```sh
npm install @0disoft/universal-config-engine-core@1.0.0-rc.4
npm install @0disoft/universal-config-engine-node@1.0.0-rc.4
npm install --save-dev @0disoft/universal-config-engine-cli@1.0.0-rc.4
```

Optional validator integrations remain
`@0disoft/universal-config-engine-validator-ajv` and
`@0disoft/universal-config-engine-validator-zod`. Install every Universal Config
Engine package at the same RC4 version.

RC4 publishes under npm `next`; npm `latest` remains `0.6.0` until stable
promotion.
