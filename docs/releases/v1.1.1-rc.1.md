# Universal Config Engine 1.1.1-rc.1

Release candidate for a source-count resource-limit fix. All five packages use
`1.1.1-rc.1` and publish under npm `next`; `latest` remains on `1.1.0`.

## Source Count Rejection

`resolveConfig` now rejects inputs exceeding `maxSources` before copying or
sorting the complete source list. It reads at most the first `maxSources` source
descriptors and does not inspect priorities or values on count rejection.

Failure metadata now retains that declaration-order prefix, replacing the former
globally priority-selected subset. Consumers inspecting `sources` on failed
oversized inputs should account for this ordering change. Valid input ordering,
stable priority ties, merge behavior, error code and diagnostic schema are unchanged.

A deterministic 100,000-source probe with `maxSources: 64` reduced source reads
from 100,000 to 64 and priority reads from 3,031,962 to zero. Regression tests cover
normalized limits, early rejection and exact-limit precedence.

No new exports, public types, dependencies or migration steps for valid inputs.
Node.js >=24 and ESM remain required. Install the exact candidate or npm `next`;
stable promotion requires successful candidate publication and exact-commit gates.
